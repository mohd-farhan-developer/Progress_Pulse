# Progress Pulse (进度脉冲)

进度脉冲（Progress Pulse）允许您将 NVDA 进度条的提示音替换为您喜欢的声音。您可以选择自定义音频文件，为进度条的开始、半程和结束设置独立的音效，并在操作完成时听到 NVDA 播报类似于“下载完成”的提示。

## 插件功能

- 在进度条每次变化时播放悦耳的声音，取代 NVDA 默认的提示音。您可以从 14 种内置音效中进行选择，或者使用您自己的音频文件。
- 声音音调会随着进度的增长而升高，让您可以直观地听到进展情况。
- 可选功能：随着进度的上升，声音会从左耳移动到右耳（声相渐变）。
- 可选功能：为进度条开始、达到 50% 和达到 100% 设置独立的提示音。
- 当进度条完成时，NVDA 会播报具体的完成事项，例如“下载完成”、“解压完成”、“复制完成”或“安装完成”。
- 当多个进度条同时移动时，声音依然清晰顺畅，不会出现卡顿或断续。您也可以允许它们重叠播放。单个进度条始终遵循 NVDA“对象呈现”设置中指定的提示音间隔。

## 快速入门

1. 安装插件并重启 NVDA。
2. 打开 NVDA 菜单（NVDA+N），依次进入“偏好设置” -> “设置”。
3. 在分类列表中选择“进度脉冲”。
4. 根据需要修改设置，然后点击“确定”。

插件安装后即可直接使用，无需额外配置：默认进度播放“水滴”音效，完成时播放“成功钟声”。

## 设置项说明

- **播放我自己的进度条声音，而不是 NVDA 的蜂鸣音**：开启或关闭插件的声音。关闭时，您将听到 NVDA 默认的提示音。
- **要更改的声音**：选择您想要配置的声音：
  * 常规声音：每次进度增长时播放。
  * 开始声音：进度条开始时播放。
  * 半程声音：进度条达到 50% 时播放。
  * 结束声音：进度条达到 100% 时播放。
- **声音**：选择具体的音效。在列表中上下切换时会实时试听，以便您在选择前确认。可选选项包括：
  * 无。对于开始、半程和结束声音，选择“无”时将播放常规声音；对于常规声音，选择“无”时进度过程将保持静音，仅播放开始、半程和结束声音。
  * 14 种内置音效之一：
    * 适合进度过程：水滴（Water drop）、轻柔滴答（Soft tick）、马林巴琴（Marimba）、气泡（Bubble）、卡林巴琴（Kalimba）、玻璃敲击（Glass tap）、木块敲击（Wood knock）、轻柔弹拨（Soft pluck）和 啵声（Pop）。
    * 适合进度开始：上升呼啸（Rising whoosh）。
    * 适合半程节点：叮咚（Ding-dong）。
    * 适合进度完成：成功钟声（Success chime）、单铃声（Single bell）和 关卡完成（Level complete）。
  * 自定义文件。
- **选择自定义文件**：从您的电脑中选择一个 WAV 文件。选择后会自动播放一次以供试听。
- **播放**：再次试听当前选择的声音。
- **随着进度上升音调升高的幅度**：无变化、少许、中等 或 大量。在 50% 进度时，您的声音始终以原始音调播放。开始、半程和结束声音始终以原始音调播放。
- **随着进度上升将声音从左耳移动到右耳**：0% 进度时从左耳发声，100% 时从右耳发声。
- **音量**：范围从 0 到 100。
- **当多个进度条同时移动时允许声音重叠**：关闭时，新发出的声音会打断正在播放的声音；开启时，最多可同时播放三个声音。
- **当进度条完成时进行播报**：NVDA 会播报具体完成的操作，例如“下载完成”。即使关闭了插件的音效，此语音播报依然有效。
- **测试所有声音**：在保存前，使用当前屏幕上的设置模拟从 0% 到 100% 播放所有声音。

## 使用须知与建议

- 音频文件必须为 WAV 格式。如果您使用的是 MP3 文件，请先通过 Audacity 或 GoldWave 等软件将其转换为 WAV 格式。
- 短音效（半秒以内）的效果最佳。较长的音频文件会被裁剪至 3 秒以内，并且文件开头的静音部分会被自动跳过，以确保声音能即时播放。
- 请勿移动已设置好的音频文件。如果文件被移动或删除，插件将自动回退使用默认的“水滴”音效。
- NVDA 自带的进度条设置依然有效。需在 NVDA 的“对象呈现”设置中，将“进度条输出”设为“提示音”或“语音和提示音”才能听到声音。“报告后台进度条”则决定了是否对其他窗口中的进度条发出声音。
- 完成提示的播报主要依据窗口标题判断，因此在英文界面下的效果最好。对于其他语言的窗口，NVDA 会播报“进度完成”以及相应的窗口标题。
- 如果进度条在达到 100% 前被关闭，将不会播放结束音效和完成播报。

## 快捷键设置

您可以分配一个快捷键来快速开启或关闭插件声音。打开 NVDA 菜单，依次进入“偏好设置” -> “按键与手势”，展开“进度脉冲”分类，找到“开启或关闭进度脉冲声音”命令并为其添加快捷键即可。

## 多语言支持

进度脉冲目前支持英语和简体中文（感谢 Alan86024 的贡献）。

如果您希望将其翻译为您所在地区的语言，可以从 [GitHub 仓库](https://github.com/mohd-farhan-developer/Progress_Pulse) 中下载 `progressPulse.pot`，使用 Poedit 等翻译编辑器进行翻译，并将翻译文件保存为 `addon/locale/<语言代码>/LC_MESSAGES/nvda.po`。您也可以将本帮助页面翻译为 `addon/doc/<语言代码>/readme.md`，随后在 GitHub 上提交拉取请求（Pull Request）。

## 系统要求

需要 NVDA 2022.1 或更高版本（包括适用于 Windows 7 和 8 的 NVDA 2023.3）。本插件已针对 NVDA 2025.3 和 2026.2 进行构建与测试。

### 1.1.1 版本

- 修复：在“提示音和语音”模式下，如果某个声音播放失败，可能会导致 NVDA 跳过当前百分比的朗读。修复后 NVDA 的语音朗读将始终稳定保持。

### 1.1.0 版本

- 新增 9 种内置音效：卡林巴琴（Kalimba）、玻璃敲击（Glass tap）、木块敲击（Wood knock）、轻柔弹拨（Soft pluck）、啵声（Pop）、上升呼啸（Rising whoosh）、叮咚（Ding-dong）、单铃声（Single bell）和 关卡完成（Level complete）。
- 修复：在快速移动的进度条中，部分声音会被跳过，导致未能遵循 NVDA 中设置的提示音间隔（默认为 1%）。现在每个进度条都会在 NVDA 应当发出提示音的每个步进点播放声音。
- 兼容 NVDA 2026.2。

- 首次发布。
